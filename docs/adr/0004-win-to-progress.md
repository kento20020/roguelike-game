# 0004. メタ進行は win-to-progress（クリア時のみ成長）とする

## Status

Accepted（2026-07-11・デザイナーレビュー反映で明文化。設計自体は v0.7 から）

## Context

- ローグライトのメタ進行には「死亡でも成長する方式」（周回するだけで必ず前進する）と「クリア時のみ成長する方式」（win-to-progress）がある（§2.1・§12.3）。
- 本作の3本柱③は「知識が報われる」（§3）。キャラの数値ではなくプレイヤーの理解の蓄積を上達の主軸に置く。
- 一方で現状の実測クリア率は目標帯 25〜40% に未達（maxed 10.2%・§18.2）であり、初心者は初クリアまでメタ進行を一切体験できない。この組み合わせは離脱リスクを持つ（OPEN-029）。

## Decision

v1.x では、恒久強化ポイントは**クリア時のみ +1** 付与する（死亡では付与しない）。

理由:
- 勝利の価値を最大化する（「全てを賭けた一勝負」のテーマと一致）
- 上達の主軸を知識（検死レポート・調書・敵の手筋読み）に置き、周回による数値インフレで難易度設計が崩れるのを防ぐ
- 死亡時の報酬は「学び」（検死レポート §15.2・調書 §15.3）で与える——数値ではなく情報で報いる設計

## Consequences

- 勝利体験が希少で重くなる。恒久強化の配分（§12.3）は「ご褒美」として機能する。
- **リスク（明示的に引き受けるもの）**:
  - 初心者が初クリアまでメタ進行を体験できない（強化システムの存在に気づかれにくい）
  - クリア率が低い間は「何度死んでも強くならない」と感じられ、離脱点になり得る
- **緩和策（実施中/計画中）**:
  - 初クリアまでの期待ラン数を観測指標として監視する（§18.1・OPEN-029。閾値は置かず、超過が見えた場合のみ救済＝到達フロア別の微小ポイント等を検討する）
  - 死亡時の学習装置（検死レポート・リプレイ・調書）を「死の報酬」として厚くする
  - Phase1 の数値調整（OPEN-030）でクリア率を目標帯 25〜40% に載せることが、本設計が成立する前提条件
- この決定を変更する場合（死亡報酬の導入）はクラスS（docs PR 先行）で本 ADR を改訂する。
