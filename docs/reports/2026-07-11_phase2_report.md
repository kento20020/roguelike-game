| 閾値 | 値 | 意味 |

## 2. 結果サマリー

| 検査 | 判定 | 実測 |
|---|---|---|
| **スキル幅（厳格ゲート）** | **PASS** | maxed 82.5% vs random 0.0%。McNemar（CRN対標本）reject・方向正。Wilson CI 非重なり：差の下限 **≈79.6pt ≥ X=20pt**。帯基準の mid でも 31.1% vs 0.0%＝差の下限 **≈27.9pt ≥ 20pt** |
| 初手別クリア率差 ±5pt（maxed・n=300/初手） | PASS | L 80.3 / M 78.7 / R 78.3%・spread **2.0pt** |
| **初手別クリア率差 ±5pt（mid・n=1000/初手・追試）** | **warn（超過）** | **L 31.1 / M 24.8 / R 24.9%・spread 6.3pt > 5pt**。L>M・L>R が FDR 有意（e-BH）。→ OPEN-045 |
| 選択感度 ≥ Y=2pt（maxed） | warn | 有意差なし（天井 80% 付近で差が圧縮） |
| **選択感度 ≥ Y=2pt（mid・追試）** | **PASS** | 効果量 6.3pt ≥ 2pt かつ FDR 有意＝「初手選択には意味がある」ことを実証 |
| 死亡フロア集中（Z=50%） | PASS | 全strong合算 2F:30 / 3F:425 / 4F:626 / 5F:771。最終フロア以外の最大シェア＝4F **33.8% < 50%**（ツール判定も max_share 41.6%＝5F込みで pass） |
| random 1〜5%（暫定） | warn | 0.0%（2Fでほぼ全滅・継続課題） |

**Phase2 の結論**：厳格ゲート（スキル幅）は事前登録値を大幅に上回って PASS。選択感度は**帯基準の mid パネルで実証**された。ただし同じ測定が「初手 L（削り合い）が M/R（賭け）より +6.3pt 有利」という**±5pt 違反**を検出した——「感度がある」と「偏りがない」はトレードオフであり、mid での偏り是正はデザイナー判断（OPEN-045）。

## 3. 測定上の注意（ツールと基準のずれ）

- `balance_report.py` の初手別・選択感度は **maxed パネル固定**で測る実装。v1.10 で帯基準が mid になったため、天井効果で感度を見逃す（本レポートの mid 追試で顕在化）。**初手別・感度の測定パネルを mid へ変更するツール改修を推奨**（クラスR・小）。
- `death_floor_concentration` は最終フロアを除外しない実装（§18.1 は「最終フロア以外」）。今回は両解釈とも PASS のため実害なし。改修時に併せて是正。

## 4. 副次的発見（Phase3/4 の予告）

1. **strong bot は scout・ゲート保証・宝箱リロールを一度も使わない**（n_used=0/3000）。sink ROI の観察値がこの3種で無意味になっており、**バランス検証の bot 人間代表性（§18.1 前提）の穴**。ゲート保証の価値（balance_model §3：5Fで−3.5pt/50G）は bot では未検証 → OPEN-046
2. **単一mod寄与（観察値）は交絡で使えない**：全profile合算の観察的寄与が全mod +35〜49pt と出るが、これは「mod を多く取る＝長く生存＝クリアしやすい」の逆因果。±8pt 判定は ablation（強制ビルド比較・INTEGRATION.md の forced_first_mod 未実装）が必要
3. **貯め込み**：hoarder率 23.2%・平均余剰 353G（獲得の24.7%）。balance_model §4 の「経済が終盤過剰」と整合（Phase4/OPEN-003）
4. fun 指標：close_win_rate 0.0（クリア時平均HP≈90＝薄氷勝利が無い）・mod多様性 0.99（袋が均等）・クリア平均76.8ターン
