# 地下カジノ・探索と戦闘 — Floor 02

確率ベースの戦闘を核にした、地下カジノ・賭博都市が舞台のパーマデス制ローグライト。
その **地下二階（Floor 02）の「探索 → 戦闘」スライス** を、単一HTMLで遊べる形に実装したもの。

Claude Design のプロトタイプ（`地下カジノ・探索と戦闘.dc.html`）を、`support.js` / React 依存を排した
**素の HTML / CSS / JS** に 1:1 移植している。ビルド不要・ブラウザで開くだけで動く。

```
オンラインで遊ぶ:  index.html をダブルクリック（または任意のブラウザにドラッグ）
```

外部依存は Google Fonts（Instrument Serif / Geist / JetBrains Mono / Noto JP）のみ。
オフラインでもシステムフォントにフォールバックして問題なく動作する。

## 遊び方

下の卓（row1）から相手を選び、アンロックを連鎖させて上の **胴元の関門（GATE）** を目指す。

| 操作 | 内容 |
|------|------|
| **ノードを選ぶ** | 枠が光る卓だけ選択可能。敵=偵察→戦闘 / 宝箱=技を入手 / 控え室=回復 / 関門=フロア突破 |
| **攻撃する** | 戦闘中、攻撃のたびに相手が確率で反応（反撃・強打・蓄積・空振り） |
| **Chips Sink** | 画面下のツールバー。スカウト(15) / 小回復(20) / 大回復(40) をチップで購入 |
| **技（技 ▾）** | ヘッダー右上。所持 mod とその効果を常時確認できる |

勝てば次ノードがアンロックされチップを獲得。HP0 で敗北（パーマデス）、関門突破で勝利。

### 体験タイプ（相手の傾向）

数値（確率）は伏せられ、アイコンと「傾向」だけが質感として開示される（暗黙知型）。

| 傾向 | 色 | 主行動 | 性格 |
|------|----|--------|------|
| 削り合い | 青 | counter | じわじわ削る・堅実 |
| 賭け | 赤 | heavy_blow / none | 大当たりか空振り |
| レース | 金 | ramp_hit | 長引くほど重い（蓄積） |
| ずれ | 緑 | evade | 攻撃を空振りさせる |
| カオス | 紫 | 複合 | 予測不能（ラン毎に変動） |

### 技（mod）

初期所持は **反射**・**見切り**。宝箱からさらに 重装甲 / 好機 / 先読み / 加速止め を入手できる。

## 実装メモ

- **単一ファイル** `index.html` — 状態 → `render()` で全 DOM を文字列生成 → `#app.innerHTML` に反映する
  素朴な再描画モデル。クリックは `#app` 1つへのイベント委譲（`data-act` 属性でディスパッチ）。
- **ゲームロジックはプロトタイプと完全一致**：ノードツリー（形A [3,4]）、アンロック連鎖（多親/単親）、
  行動テーブルのロール、反射 +4・見切り evade 半減などの mod 効果、ゲート確率テーブル（2F: 25/45/25/5）、
  チップ sink、偵察・勝敗・関門の各モーダル。
- **ビジュアルもプロトタイプ準拠**：チャコール＋フェルトの地下カジノ配色、セリフ見出し＋モノスペース数値（tabular-nums）、
  絵文字を使わないストロークアイコン、立ち上る煙（ember）・かすみ（haze）・ヴィネット。
- 戦闘ログは全履歴保持。最新行へ自動スクロール。

### 検証

`node` による無依存スモークテストで、探索→偵察→戦闘→攻撃ループ→勝敗、スカウト/回復 sink、宝箱、回復、
関門→終了→リセットまでの状態遷移を確認済み（24チェック）。視覚はヘッドレス Edge でスクリーンショット確認済み。

### どんなゲームをイメージして作ったか

確率ベースの戦闘を核にした、**カジノタワーを登り詰める** 5フロアのパーマデス制ローグライト。
薄暗い賭博都市のタワーを舞台に、下の卓から相手を選んで勝ち上がり、各フロアの「胴元の関門」を突破して頂上を目指す（描画は下から上へ＝Slay the Spire 型）。

設計の軸は3つ：

- **ギャンブルの質感** — 攻撃のたびに相手が確率で反応する（反撃・強打・蓄積・空振り）。確率は数値で見せず「傾向」だけを質感として開示する **暗黙知型**。
- **攻めと守りのリスク選択** — チップ（ゴールド）で「リスクを減らす」だけでなく「リスクを取って攻める」選択肢も用意。ただし **お金で完全な安全（確実突破）は買えない** 構造にして、ギャンブルというテーマと整合させる。
- **パーマデス** — HP0 で全てを失う一回性の緊張感。強プレイのクリア率を 25〜40% に置く想定。

技術構成は **React（表示）＋ FastAPI（全ロジック）** のモノレポ。ゲームロジックはすべて Python 側に集約し、**同じエンジンを API と bot シミュレーション（バランス検証）の両方が呼ぶ**。React は計算せず結果を表示するだけ。
