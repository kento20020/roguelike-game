# カジノタワー ローグライト

確率ベースの戦闘を核にした、**カジノタワーを登り詰める** 5フロアのパーマデス制ローグライト。
下の卓から相手を選んで勝ち上がり、各フロアの「胴元の関門（GATE）」を突破して頂上（5F）を目指す（描画は下から上へ＝Slay the Spire 型）。

技術構成は **React（表示）＋ FastAPI（全ロジック）** のモノレポ。ゲームロジックはすべて Python 側に集約し、
**同じエンジンを API と bot シミュレーション（バランス検証）の両方が呼ぶ**。

## 起動方法

```
# backend（FastAPI / 全ロジック）— http://localhost:8000
cd backend && pip install -r requirements.txt && uvicorn main:app --reload

# frontend（React / 表示）— http://localhost:5173
cd frontend && npm install && npm run dev
```

## 遊び方

下の卓（row1）から相手を選び、アンロックを連鎖させて上の **胴元の関門（GATE）** を目指す。

| 操作 | 内容 |
|------|------|
| **ノードを選ぶ** | 枠が光る卓だけ選択可能。敵=偵察→戦闘 / 宝箱=技を入手 / 控え室=回復 / 関門=フロア突破 |
| **攻撃する** | 戦闘中、攻撃のたびに相手が確率で反応（反撃・強打・蓄積・空振り） |
| **Chips Sink** | 画面下のツールバー。スカウト(15) / 小回復(20) / 大回復(40) をチップで購入 |
| **技（技 ▾）** | ヘッダー右上。所持 mod とその効果を常時確認できる |

勝てば次ノードがアンロックされチップを獲得。各フロアの関門を突破し、頂上（5F）まで登り切れば勝利。
HP0 で敗北＝パーマデス（一回性の緊張感）。

### 体験タイプ（相手の傾向）

数値（確率）は伏せられ、アイコンと「傾向」だけが質感として開示される（暗黙知型）。全36体がこの傾向のいずれかに属し、
カオス系（`chaos:true`）はランごとに行動が変動する。

| 傾向 | 色 | 主行動 | 性格 |
|------|----|--------|------|
| 削り合い | 青 | counter | じわじわ削る・堅実 |
| 賭け | 赤 | heavy_blow / none | 大当たりか空振り |
| レース | 金 | ramp_hit | 長引くほど重い（蓄積） |
| ずれ | 緑 | evade | 攻撃を空振りさせる |
| カオス | 紫 | 複合 | 予測不能（ラン毎に変動） |

### 技（mod）

初期所持は **反射**・**見切り**。宝箱からさらに 重装甲 / 好機 / 先読み / 加速止め を入手できる。
mod の効果文は `backend/app/data/mods.json` が正本で、API `GET /api/catalog/mods` から取得する。

## アーキテクチャ（4つの枠）

このプロジェクトは **フロント / バック / データ / データベース** の4つに大きく分かれる。

```
┌────────────────────────────────────────────────────────┐
│ ① フロント (Frontend) — React + TypeScript + Vite      │
│    Zustand（状態管理）/ Tailwind（見た目）/             │
│    gameApi.ts（API通信を集約）                          │
│    ※ 計算しない。バックが返す結果を表示するだけ         │
└─────────────────────────┬──────────────────────────────┘
                          │ REST API (HTTP / JSON)
                          ▼
┌────────────────────────────────────────────────────────┐
│ ② バック (Backend) — Python + FastAPI                  │
│    GameEngine（全ロジック）/ FloorGenerator /           │
│    CombatResolver / GateResolver / SQLAlchemy(ORM)      │
│    ※ ロジックは全てここ。API と bot 検証が同じエンジン共用│
└──────┬─────────────────────────────────┬───────────────┘
       │ 読み込み（起動時・参照）          │ 永続化（SQLAlchemy 経由）
       ▼                                 ▼
┌──────────────────────────┐  ┌───────────────────────────┐
│ ③ データ (Data)          │  │ ④ データベース (Database)  │
│   backend/app/data/*.json │  │   SQLite (game.db)         │
│   config / enemies(36体) /│  │   run_records（プレイ統計）/│
│   mods(6種) / floors(5F)  │  │   profiles（恒久強化）     │
│   ※ 数値の正本・読み取り専用│  │   → 将来 PostgreSQL へ移行 │
└──────────────────────────┘  └───────────────────────────┘
```

| 枠 | 役割 | 性質・技術 |
|----|------|-----------|
| ① フロント | 画面表示のみ（計算しない） | React / Vite / Zustand |
| ② バック | 全ゲームロジック・API | Python / FastAPI |
| ③ データ | 設計の正本（係数・敵36体・技6種・5フロア） | 静的 JSON・**読み取り専用** |
| ④ データベース | プレイ統計・恒久強化の永続 | SQLite・**実行時に書き込み**（→PostgreSQL） |

**③データ と ④データベースの違い**：③は人間が決める静的な設計値（読み取り専用の正本）、④はプレイや bot が実行時に書き込む永続データ。同じ「データ」でも役割がまったく異なるため枠を分けている。

## 実装メモ

- **ゲームロジックは全て Python**（`backend/app/engine`）。React は計算せず、バックエンドが返す完全なゲーム状態を表示するだけ。
- **同じエンジンを API と bot シミュレーションの両方が呼ぶ**。UI 用と検証用でロジックを分岐させない。
- フロントの状態管理は **Zustand**（`frontend/src/store`）。API 通信は `frontend/src/api` に集約。
- 数値（戦闘係数・敵36体・技6種・5フロア構成・ゲート確率）の正本は `backend/app/data/*.json`（`config` / `enemies` / `mods` / `floors`）。README やコードにハードコードしない。

### 検証

- **pytest** によるエンジンのテスト（TDD 寄り）: `cd backend && pytest`
- **bot シミュレーション**でバランスを検証: `cd backend && python -m app.simulation.phase12_harness`

### どんなゲームをイメージして作ったか

確率ベースの戦闘を核にした、**カジノタワーを登り詰める** 5フロアのパーマデス制ローグライト。
薄暗い賭博都市のタワーを舞台に、下の卓から相手を選んで勝ち上がり、各フロアの「胴元の関門」を突破して頂上を目指す（描画は下から上へ＝Slay the Spire 型）。

設計の軸は3つ：

- **ギャンブルの質感** — 攻撃のたびに相手が確率で反応する（反撃・強打・蓄積・空振り）。確率は数値で見せず「傾向」だけを質感として開示する **暗黙知型**。
- **攻めと守りのリスク選択** — チップ（ゴールド）で「リスクを減らす」だけでなく「リスクを取って攻める」選択肢も用意。ただし **お金で完全な安全（確実突破）は買えない** 構造にして、ギャンブルというテーマと整合させる。
- **パーマデス** — HP0 で全てを失う一回性の緊張感。強プレイのクリア率を 25〜40% に置く想定。

技術構成は **React（表示）＋ FastAPI（全ロジック）** のモノレポ。ゲームロジックはすべて Python 側に集約し、**同じエンジンを API と bot シミュレーション（バランス検証）の両方が呼ぶ**。React は計算せず結果を表示するだけ。
