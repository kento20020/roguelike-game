# デザイン仕様 — チップ演出＆敵カードモチーフ（戦闘画面拡張）

Claude Design で `.dc.html` を起こすための**画面仕様の正本**。対象は**CombatPanel（戦闘画面）の視覚拡張**：①サイドベット「読み宣言」のチップ演出、②敵の視覚表現のトランプ風カードモチーフ化。どちらも既存データのみで賄える**純粋な視覚拡張**（新規バックエンドAPI・新規フィールドは不要）。

> 進め方（CLAUDE.md準拠）: この仕様 → Claude Design で複数コンセプト案の `.dc.html` を作成 → `design/` に取り込み → 方向性を1つに絞って React化。
> 見た目の正本はデザイン側に残す。レイアウトを白紙から手書きで起こさない。

> **背景**: サイドベット（GDD §15.4）は実装済みだが、賭け額の増減は数字ボタンと枠線色の変化だけで、「チップを賭けている」実感に乏しい。敵の表示（`CombatPanel` 冒頭）も名前＋アイコン＋HPバーのみで、経験タイプ（`Motif.tsx`）は抽象的な折れ線に留まる。本specはこの2点を、既存のカジノ・ノワール視覚言語の中で強化する。

## 1. 現状の課題→方針

| 対象 | 現状 | 課題 | 方針 |
|---|---|---|---|
| サイドベットの賭け額・結果 | 5/10/20の数字ボタン＋的中/外れの色付きピル（`sideBetHit`/`sideBetMiss`） | 数字と枠線の色が変わるだけで「チップを賭けている」実感がない | 実際のチップ（枚数のスタック）グラフィックを追加。選定→コミット→結果まで、チップが卓上を移動する演出にする |
| 敵の視覚表現 | 名前(serif)＋経験タイプの小ピル(`Motif`は抽象折れ線)＋HPバー | 敵ごとの見分けが薄く、経験タイプも図案として弱い | 敵をトランプ風のカードフレームで表現。経験タイプ＝縁色・コーナーマーク、モチーフアイコンを中央に大きく配置 |

## 2. データ契約（既存のみ・変更なし）

### 2.1 サイドベット関連（`Battle` 型・既存）
```
side_bet: { min_amount: 5, max_amount: 20, payout_multiplier: 3, per_battle_cap: 40 }
side_bet_total?: number          // 戦闘あたりの賭け累計
side_bet_result?: { hit: boolean; payout: number } | null  // 直近ターンの的中/外れ結果
```

賭け額プリセットは `SIDE_BET_AMOUNT_PRESETS = [5, 10, 20]`（フロント定数・UI表現のみ）。

### 2.2 敵・経験タイプ（既存）
```
enemy.experience: "削り合い" | "賭け" | "レース" | "ずれ" | "カオス"
enemy.is_strong: boolean         // 既存「大物」ピルの根拠
experienceMeta(exp) -> { jp, en, iconType, color, tend }
```

### 2.3 敵の行動（サイドベット対象・既存 `BEHAVIOR`）
反撃／強打／回避／蓄積の一撃／様子見（アイコン・色は `labels.ts` の `BEHAVIOR` が正本）。

## 4. 画面構成

### A. チップ演出（サイドベット枠内の拡張）

1. **賭け額選択**：現状の5/10/20の数字ボタンを、チップが積まれたスタックのグラフィックに置き換える（枚数はプリセットの大小を表現する程度でよく、厳密な計算は不要＝表示専用）。選択中のスタックは少し浮き上がる／縁が光る。
2. **コミット時**（攻撃/受けボタンを押した瞬間）：選択したチップスタックが賭け枠から卓中央寄りへスライドし、「賭け中」の状態で留まる演出。
3. **結果判定時**（`side_bet_result` 到着時）：
   - 的中（`hit: true`）→ チップが3倍（`payout_multiplier`）の量になって真鍮の輝きとともに手前へ戻ってくる。
   - 外れ（`hit: false`）→ チップが煤（すす）のようにフェードして消える、または卓の奥へ沈む。
4. 賭け累計メーター（`capTotal`/`perBattleCap`）は既存の `HpBar` 流用のままでよいが、チップの意匠とトーンを合わせる。

### B. 敵カードモチーフ（戦闘画面の敵ヘッダー部）

現状の「経験タイプの小ピル＋名前＋HPバー」を、トランプ風の縦長カードフレームに刷新する。

- 上部コーナーに経験タイプのマーク（トランプの隅の数字/スート位置を借用し、小さくアイコン＋タイプ名）
- 中央に敵のモチーフアイコンを大きく配置（現状の抽象折れ線ではなく、視認性の高いシンボルへ格上げ）
- 下部にHPバー（既存 `HpBar` 流用）
- 外周の縁色は経験タイプ色。`is_strong`（大物）の敵は縁を二重線＋真鍮アクセントにするなど、既存「大物」ピルの意味を引き継ぐ

5体の代表敵は、**同一のカードフレーム意匠のまま色とモチーフだけ差し替えたバリエーション**として並べ、一貫性を確認できるようにする。

---

## 5. 演出方針

- チップ演出は既存の抑制されたFXトーン（`dmgPop`／`sideBetHit`/`sideBetMiss`）に合わせ、回転・弾みすぎるような過剰な物理演出は避ける。スライド＋フェード＋輝きの範囲に留める。
- 敵カードモチーフは戦闘中ずっと表示され続けるため、常時アニメーションはさせない（登場時の `fadeUp` 程度のみ。以降は静止）。
- どちらも「カジノの卓上」という世界観を強めるが、既存の落ち着いたトーン（煤けた紙・暗色地に朱と真鍮のアクセント）を維持し、ポップになりすぎない。

---

## 6. 着手前に潰す確認ポイント

1. チップ演出を置く場所：現状のサイドベット枠内に収めるか、卓中央に新しい共有スペースを設けるか。
2. 敵カードモチーフ導入時、既存のHPバー・先読み/スカウト/テル表示をカードの内側に統合するか、カードの下に従来通り並べるか。
3. チップのグラフィック（枚数・厚み・色）をどこまで作り込むか（表示専用のため、正確な金額比例は不要）。

これらは Claude Design のコンセプト案を実際に見てから判断する（抽象的な多肢選択では決めない）。
