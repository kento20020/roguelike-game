カジノを舞台にしたローグライトの**戦闘画面（CombatPanel）を拡張する2つの演出**を、1つのインタラクティブなプロトタイプとして作ってください。既存の戦闘画面レイアウト（敵名見出し→経験タイプの帯→HPバー→先読み/スカウト/テル→戦闘ログ→自分のHPパネル→攻撃/受けボタン）はそのまま踏襲し、**サイドベット（チップを賭ける枠）と敵ヘッダー部の意匠だけ**を拡張します。上部に切り替えトグルを置いてください：**「①チップ演出A」「②チップ演出B」「③チップ演出C」「④敵カードモチーフ」**（すべて同一のダミー戦闘状態を土台にする）。

## 世界観・ムード
高層のカジノタワー。煤けた紙のような暗色地、朱（`--accent`／危険寄り）と真鍮（`--brass`／的中・勝利）のアクセント。落ち着いた質感を保ちながら、「賭けている」「相手の手札」という卓上の実在感を強める。ポップになりすぎない・下品な光り方をしない。

## 前提として毎回表示するもの（既存のまま・変更しない）
- 敵名（serif・35px程度）＋経験タイプの帯（アイコン＋日本語名＋色。5種：削り合い`#6E93B8`／賭け`#C2493B`／レース`#C9A24B`／ずれ`#5E9A78`／カオス`#9C79BC`）
- 敵HPバー（`--accent`系統）／自分のHPバーと攻撃力
- 戦闘ログ（直近の行動テキスト）
- 攻撃する／受ける の主・副ボタン

## 追加①〜③：チップ演出（同じ賭け枠に3方向のバリエーション）

現状のサイドベット枠は「見送る＋5種の行動アイコンボタン」「賭け額5/10/20の数字ボタン」「賭け累計メーター」「的中/外れの色付きピル」だけで構成されています。これを**実際にチップが動く**演出に格上げする、異なる3方向を作ってください（トグルで切り替え）。

- **共通の状態遷移**：①賭け額を選ぶ（チップのスタックが浮き上がる）→②攻撃/受けを押してコミットする（チップが賭け枠から卓side中央寄りへスライドし「賭け中」の状態で留まる）→③結果が出る（的中＝3倍の量になって真鍮の輝きとともに手前へ戻る／外れ＝煤のようにフェードして消える）。
- **演出A**：チップは丸いコイン状。賭け額5/10/20をそれぞれ「薄い/中/厚いチップの束」の高さで表現。派手な物理演出（弾む・回転）はしない。スライドとフェードのみ。
- **演出B**：チップは卓の縁の「ベットライン」に沿って賭け額ぶんの小さな円が並ぶ形。的中時は円が真鍮色に染まって数が3倍に増える、外れ時は円が縦に短く縮んで消える。
- **演出C**：チップは賭けている行動アイコン（反撃/強打/回避/蓄積の一撃/様子見のいずれか）にチップの意匠を重ねたバッジ状。宣言している行動そのものにチップが乗っているように見せる。的中時はバッジごと真鍮に発光、外れ時は静かに彩度が落ちて消える。
- 3方向とも、賭け累計メーター（現状の細いバー）は残してよいですが、チップの意匠とトーンを揃えてください。

## 追加④：敵カードモチーフ（トランプ風フレーム・代表5体）

現状の敵ヘッダーは「経験タイプの小さな帯＋名前＋HPバー」だけです。これをトランプ風の縦長カードフレームに刷新した1つの意匠で、**経験タイプ5種を代表する敵5体**を並べて見せてください（同じフレーム・色とモチーフだけが違う、という一貫性を確認したいため）。

| 経験タイプ | 敵名 | 縁色 |
|---|---|---|
| 削り合い | 鉄塔の門番 | `#6E93B8` |
| 賭け | 死闘の博徒 | `#C2493B` |
| レース | 雷式ディーラー | `#C9A24B` |
| ずれ | 残影の手品師 | `#5E9A78` |
| カオス | 嵐の胴元 | `#9C79BC` |

- カードフレームの構成：上部コーナーに経験タイプの小さなマーク（トランプの隅の数字/スートの位置を借用。アイコン＋タイプ名）／中央に敵を象徴するモチーフアイコンを大きく配置／下部にHPバー。
- 外周の縁は経験タイプ色。「大物」の敵（今回は死闘の博徒を大物として扱う）は縁を二重線＋真鍮アクセントにする。
- カードは戦闘中ずっと表示され続けるため、常時アニメーションはさせない（登場時にふわっと現れる程度）。
- 5枚は横並び、または戦闘画面にはめ込んだ状態（1枚だけ実戦配置の見本、残り4枚は比較用に下に並べる、など見やすい形で構いません）。

## ダミーデータ（スロットを正しく作るための仮値）
- 賭けの規則：`min=5 / max=20 / 的中倍率=3 / 戦闘あたり上限=40`。賭け額プリセットは5・10・20。
- チップ演出のデモ：賭け額10を「蓄積の一撃」に宣言 → コミット → 的中（+20の払い戻し、真鍮演出）というシーケンスと、外れ（-10、煤フェード演出）というシーケンスの両方を再生できるようにする。
- 敵カードモチーフのデモ：5体それぞれ HP は最大値の6〜7割程度で表示。

技ピル・HPバー・主/副ボタン・アイコン語彙（反撃=reflect／強打=sword／回避=evade／蓄積の一撃=race／様子見=eye）は既存の探索/戦闘画面と同じ部品を使ってください（後でReactの共通コンポーネントに落とします）。

## 取り込み後にこちらでやること
1. 生成 `.dc.html` を `design/` に保存。
2. チップ演出A/B/Cを見比べて1方向に決める（人間が決定。統計指標ではなく見た目の判断）。
3. 敵カードモチーフのフレーム意匠を確認し、既存のHPバー・先読み/スカウト/テル表示をカード内に統合するかどうかを実装しながら判断する（`spec_chip_fx_and_enemy_card_motif.md` §6）。
4. React化：`CombatPanel.tsx` のサイドベット枠と敵ヘッダー部を、決定した意匠に置き換える。ロジック（`side_bet`/`side_bet_total`/`side_bet_result`・`experienceMeta`）は変更せず、見た目のみ差し替える。
5. 残り31体への展開は、決定したカードフレームに色とアイコンを差し替えるだけで済むかを確認する。
